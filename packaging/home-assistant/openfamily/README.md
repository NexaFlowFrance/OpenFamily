# OpenFamily

The family organizer you host yourself: a shared calendar with reminders, tasks and chores with a rewards system for kids, shopping lists updated live on every phone, meal planning with a recipe book, and a family budget.

This app runs the whole of OpenFamily next to Home Assistant: the web interface, the API and its database. There is nothing to configure before the first start.

OpenFamily also talks to Home Assistant itself: its documented API, personal tokens and webhooks let your automations read the family's day or add to the shopping list.
